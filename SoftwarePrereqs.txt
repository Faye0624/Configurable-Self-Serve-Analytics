HOW TO RUN IT
=============

1. Python 3.13 is required (3.10 or newer will work).

2. From the project root, create and activate a virtual environment:

       python -m venv .venv
       source .venv/bin/activate          # Windows: .venv\Scripts\activate

3. Install the dependencies:

       pip install -r requirements.txt

4. Start the application:

       streamlit run app/main.py

   It opens at http://localhost:8501.

5. To run the tests:

       pytest -q

   For coverage:

       pytest --cov=ssa --cov-report=term:skip-covered -q


NOTES
=====

No API key is needed.
  The natural-language query feature uses an offline, rule-based stub unless
  an OpenAI API key is supplied. Everything else — upload, profiling,
  cleaning, configuration, progressive unlock, the dashboard, the generated
  SQL and the query history — works fully without one.

To enable the real model, put a key in a .env file in the project root:

       OPENAI_API_KEY=sk-...
       SSA_LLM_MODEL=gpt-4o-mini        (optional; this is the default)

No database setup is required.
  DuckDB is embedded. The application creates its own files on first run:
  workspace.duckdb for accounts and the project list, and one <project id>.duckdb
  per project under projects/.

Sample data.
  sample_data/study/ contains the two CSV files used in the user study
  (orders.csv and order_items.csv), drawn from the public Olist Brazilian
  e-commerce dataset. Uploading orders.csv first and order_items.csv second
  demonstrates progressive unlock.
